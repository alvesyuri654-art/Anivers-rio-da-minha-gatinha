# Mini-site de aniversário ❤️

## Como alterar as fotos

1. Coloque as fotos na pasta `images`.
2. Abra `content.js`.
3. Em cada secção, troque:
   `photo:null`
   por algo como:
   `photo:"images/foto-primeiro-beijo.jpg"`
4. Salve e abra `index.html` no navegador.

Os textos também ficam todos em `content.js`, separados do visual.

## Publicação

A pasta inteira pode ser publicada em serviços como GitHub Pages, Netlify ou Vercel.
Depois de publicado, o endereço final pode ser transformado em QR Code.

## Observação

O site já funciona sem fotos: os espaços aparecem como placeholders, para que seja fácil identificar onde cada imagem entrará.
